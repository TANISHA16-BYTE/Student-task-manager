
# TaskFlow — Student Task Manager

TaskFlow is a simple task management web application designed to help students organise their daily work, track pending tasks, and monitor completed tasks.

## Features

- Add new tasks
- Mark tasks as completed
- Undo completed tasks
- Delete tasks
- Filter tasks by All, Pending, and Completed
- Dashboard showing task statistics
- Responsive interface for mobile and desktop
- SQLite database for storing tasks

## Technologies Used

- Python
- Flask
- SQLite
- HTML5
- CSS3
- Jinja2 Templates

## Getting Started

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd Student-Task-Manager
```

### 2. Install dependencies

```bash
python3 -m pip install flask
```

### 3. Run the application

```bash
python3 app.py
```

### 4. Open in your browser

Visit: http://127.0.0.1:5000

## Learning Outcomes

This project demonstrates basic backend development, routing, form handling, database operations, HTML templating, and responsive CSS styling.
